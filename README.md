### [微信公众号写作助手](https://github.com/JoyZhang666/joy-agent-skills/blob/main/kb-to-wechat-article/README.md) · 重点推荐

**把笔记、资料和想法，整理成有依据、好读、方便你修改的公众号文章。**

- **你给什么**：一个主题，或你有权使用的笔记、文字和文件，再说说写给谁看。
- **拿到什么**：标题建议、提纲、Markdown 文章草稿，以及待核对的事实和来源。
- **怎样开始**：新手逐步引导；没有知识库、还没开通公众号，也可以先写第一篇。
- **按需扩展**：配图、排版、Word 定稿转换与手机预览；配置接口并授权后可送草稿箱，公开发表由你完成。
